## 📖 1. Overview

This project demonstrates a complete workflow from **device-level simulation** to **analog circuit implementation**, using a **14nm Double Gate MOSFET (DGMOS)**. It spans TCAD device design, compact model extraction, and analog circuit design/analysis — connecting device physics to real circuit-level behavior.

---

## ✨ 2. Highlights

- 🖥️ Designed and simulated a 14nm DGMOS structure using **Sentaurus TCAD**
- 📊 Extracted device characteristics from TCAD simulations
- 🔧 Developed a **Verilog-A** compact model from the extracted data
- ⚙️ Imported the model into **Cadence Virtuoso**
- 📡 Designed and analyzed a **Common Source Amplifier**
- ⚡ Performed **DC, AC, and transient analysis**

---

## 🔗 3. Workflow

**TCAD Simulation → Parameter Extraction → Verilog-A Modeling → Circuit Design → Amplifier Analysis**

Each stage feeds directly into the next: the physical device model built in TCAD provides the raw characteristics, which are distilled into a portable Verilog-A model, which in turn drives real circuit-level simulation and analysis in Cadence.

---

## 🛠️ 4. Tools Used

| Tool | Purpose |
|---|---|
| **Sentaurus TCAD** | Device-level structural design and simulation of the 14nm DGMOS |
| **Verilog-A** | Compact model development from extracted device data |
| **Cadence Virtuoso** | Analog circuit design, simulation, and analysis using the imported model |
